Facegate has three parts:

- **Server** (`server/`): FastAPI, InsightFace ArcFace for matching, MiniFASNet and the CVPR-2024 ResNet50 gate for passive anti-spoof, a screen-flash reflection check and a smile re-check. SQLite by default, Postgres through `DATABASE_URL`. Multi-tenant: every project has an API key and its own policy.
- **Flutter package** (`packages/facegate`): `FaceVerifyView` plus the headless `FaceVerifyController`. ML Kit on iOS and Android, MediaPipe on the web.
- **React SDK** (`packages/facegate-react`): `FacegateView`, `useFacegate` and the same headless controller, MediaPipe in the browser.
