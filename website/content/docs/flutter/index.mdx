## Install

```yaml
dependencies:
  lumiface:
    path: ../lumiface/packages/lumiface   # or a git url with a tag
```

- iOS: `NSCameraUsageDescription` in `Info.plist`, platform 15.5 or newer.
- Android: `minSdk` 23 or newer.
- Web: nothing to add; the MediaPipe glue is loaded from the package assets. See [Web](/docs/flutter/web).

## The view

```dart
FaceVerifyView(
  client: LumifaceClient(baseUrl: 'https://faces.example.com', apiKey: key),
  subjectId: 'E001',          // omit for liveness only
  purpose: 'checkin',
  strings: LivenessStrings.th,
  theme: FaceVerifyTheme.fromScheme(Theme.of(context).colorScheme),
  onResult: (VerifyResult r) { ... },
  onFlashChanged: (on) => ...,  // push brightness to max while the screen flashes
)
```

It fills its parent, so put it in a `Scaffold` body or any sized box. The result arrives once through `onResult`; the default overlay then shows a Done or Try again button that pops the route.

## The result

```dart
class VerifyResult {
  bool ok;
  String mode;            // verify | liveness | enroll
  String reasonCode;      // OK or a code from the reason-codes page
  VerifyScores scores;    // match, spoof, consistency (null when not applicable)
  int? verificationId;    // set on success for verify and liveness
  Subject? subject;       // set on success for enroll
}
```

## The client

`LumifaceClient` wraps the HTTP API: `createSession`, `verify`, `enroll`, `listSubjects`, `getSubject`, `deleteSubject`, `listVerifications`, `getPolicy`, `updatePolicy`, `resetPolicy`, `listPresets`. Errors other than a verify verdict throw `LumifaceException(reasonCode, details)`.

## Theme

`FaceVerifyTheme` covers `backgroundColor`, `maskColor`, `guideColor` / `guideActiveColor` / `guideSuccessColor` / `guideFailedColor`, `guideShape` (`oval`, `roundedRect`, `none`), `guideWidthFraction`, `guideAspectRatio`, `guideCenterY`, `guideStrokeWidth`, `progressColor`, `progressBackgroundColor`, `messageStyle`, `messagePadding`, `showProgress`, `showButtons`. `FaceVerifyTheme.fromScheme(colorScheme)` derives the colours from your Material theme.

## Strings

`LivenessStrings.en` and `LivenessStrings.th`. `copyWith` replaces single lines and merges `reasons`, so a login screen can say "Welcome back" instead of "Verified" without redefining the rest:

```dart
strings: LivenessStrings.en.copyWith(success: 'Welcome back'),
```
