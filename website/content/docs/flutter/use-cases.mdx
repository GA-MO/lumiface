All five live in `examples/flutter/lib/pages/usecases_page.dart`. `backend` below is the app's HTTP client for
*your* backend (`examples/flutter/lib/example_backend.dart`), which creates the session with the project key and
decides the subject and the purpose; the app only passes the session on.

## Attendance check-in

Verify against the saved subject, label it `checkin`, a custom success line (`LivenessStrings.th` for Thai):

```dart
FaceVerifyView(
  client: client,
  sessionProvider: () => backend.createSession(subjectId: employeeId, purpose: 'checkin'),
  strings: LivenessStrings.en.copyWith(success: 'Checked in'),
  onResult: done,
  onFlashChanged: setMaxBrightness,
)
```

## Login with face

Same flow, the app's colours and a rounded guide:

```dart
FaceVerifyView(
  client: client,
  sessionProvider: () => backend.createSession(subjectId: userId, purpose: 'login'),
  strings: LivenessStrings.en.copyWith(success: 'Welcome back'),
  theme: FaceVerifyTheme.fromScheme(Theme.of(context).colorScheme).copyWith(
    guideShape: FaceGuideShape.roundedRect,
    guideWidthFraction: 0.8,
    guideAspectRatio: 1.2,
  ),
  onResult: done,
)
```

## Liveness only (kiosk, gating a form)

The backend creates the session without a subject: the server proves a live person and records the verification with `subject_id: null`.

```dart
FaceVerifyView(
  client: client,
  flow: FaceFlow.liveness,
  sessionProvider: () => backend.createSession(purpose: 'kiosk'),
  onResult: done,
)
```

## Enrol from the camera

`FaceFlow.enroll` aligns the face, captures one frontal frame and posts it with a single-use enrol token your backend minted (`POST /v1/subjects/tokens`); the token names the subject. The result carries the created `Subject` or the server's rejection code.

```dart
FaceVerifyView(
  client: client,
  flow: FaceFlow.enroll,
  enrolTokenProvider: () => backend.createEnrolToken(newId, name: 'Person A'),
  onResult: (r) => r.ok ? saved(r.subject!) : rejected(r.reasonCode),
)
```

## Custom UI

`overlayBuilder` receives a `FaceVerifyScope` (state, latest signal, strings, theme, flow, `message`, `displayBox`, `cancel()`) and draws everything on top of the preview. See [Custom UI](/docs/flutter/custom-ui).

## Screen brightness

The flash check works best at full brightness. The package adds no brightness plugin; the example uses `screen_brightness` in `onFlashChanged`:

```dart
Future<void> setMaxBrightness(bool on) async {
  if (kIsWeb) return;
  final sb = ScreenBrightness.instance;
  on ? await sb.setApplicationScreenBrightness(1.0) : await sb.resetApplicationScreenBrightness();
}
```
